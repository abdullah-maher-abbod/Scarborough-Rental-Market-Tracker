# Scarborough-Rental-Market-Tracker
**Core question:** How have rents and vacancy rates changed in Scarborough over time, and how do they compare to the rest of Toronto?  

**Tools:** SQL, Python (pandas), and a dashboard in Power BI or Tableau Public. Google Sheets alone is the weaker choice for a portfolio, since employers want to see SQL and Python.

Data source: Source: CMHC, Rental Market Survey, Toronto 2025 (data tables, October 2025). Adapted from CMHC. This project is independent and not endorsed by CMHC. See the CMHC licence agreement(https://www.cmhc-schl.gc.ca/professionals/housing-markets-data-and-research/housing-data/cmhc-licence-agreement-use-of-data)
